Muzna Nazhath — Portfolio
=========================

Static GitHub Pages portfolio built with HTML, CSS and vanilla JavaScript.

Publish:
1. Keep the repository name as MuznaNazhath.github.io.
2. Commit and push the contents of this folder to the repository's main branch.
3. In GitHub, open Settings > Pages and confirm deployment from the main branch / root.
4. The site will be available at https://muznanazhath.github.io/.

CV PDFs are stored in /documents. Update these files when replacing a CV.
Project descriptions and experience are based on the supplied project README and CVs.
